# 251 Standalone shell scripts are never shellchecked: 3 findings on main, including a cd without || exit

## Problem

actionlint (run as the Docker image, so with shellcheck) lints only the inline `run:` blocks of workflows. The standalone shell scripts that those blocks call (`scripts/*.sh`), and the experiment scripts, are never shellchecked. Nothing in `workflows.yml` or `.pre-commit-config.yaml` runs shellcheck on them. ShellCheck 0.11.0 reports the following on the current `main`:

```
experiments/budget-runner-demo.sh:4:1: warning: Use 'cd ... || exit' or 'cd ... || return' in case cd fails. [SC2164]
experiments/test-issue75-buildx-mirror-fallback.sh:102:42: note: Expressions don't expand in single quotes, use double quotes for that. [SC2016]
scripts/read-job-cancel-in-progress.sh:8:70: note: Expressions don't expand in single quotes, use double quotes for that. [SC2016]
```

`experiments/budget-runner-demo.sh:4` continues in the wrong directory if `cd` fails (SC2164). The SC2016 notes are false positives (the single-quoted text is Python or a literal pattern), which deserve a justified `# shellcheck disable=SC2016` comment so that the job can be strict.

## Reproduce

```sh
git ls-files -z '*.sh' | xargs -0 pipx run --spec shellcheck-py==0.11.0.1 shellcheck
```

## Suggested fix

Fix the findings, then add a pinned job to `workflows.yml`. Add `'**.sh'` to its `paths:` filters and the job to `pipeline-status.needs`:

```yaml
  # actionlint shellchecks only inline `run:` blocks, so the standalone
  # scripts that those blocks call were never linted. Pinned through
  # shellcheck-py so a runner image update cannot change the verdict.
  shellcheck:
    name: ShellCheck
    runs-on: ubuntu-24.04
    timeout-minutes: 10
    steps:
      - uses: actions/checkout@v6
        with:
          persist-credentials: false
      - name: Shellcheck every tracked shell script
        run: git ls-files -z '*.sh' | xargs -0 pipx run --spec shellcheck-py==0.11.0.1 shellcheck
```

and the matching pre-commit hook:

```yaml
  - repo: https://github.com/shellcheck-py/shellcheck-py
    rev: v0.11.0.1
    hooks:
      - id: shellcheck
```

Applied, with a regression test, in link-foundation/lfs#4 (link-foundation/lfs#3), which fixed the same findings that it inherited from the Rust template.
