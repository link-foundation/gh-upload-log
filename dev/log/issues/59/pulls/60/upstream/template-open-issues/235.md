# 235 detect-code-changes does not count shell scripts (.sh) as code, so a script-only PR skips the checks

## Problem

`detect-code-changes` decides `any-code-changed`, which gates these jobs: `changeset-check`, `check-file-line-limits`, `lint`, `test` and `docker-build`. Its code pattern does not include `.sh`, yet the pipeline itself runs 8 shell scripts from `scripts/` (`check-mjs-syntax.sh`, `simulate-fresh-merge.sh`, `check-file-line-limits.sh`, ...). A pull request that changes **only** a shell script therefore reports `any-code-changed=false`: it needs no changelog fragment, and all of them are skipped, so a broken script reaches `main` with a green PR.

Found while porting the template to link-assistant/calculator (https://github.com/link-assistant/calculator/issues/256, fix in https://github.com/link-assistant/calculator/pull/257, which also adds `.py` and `.json`).

## Reproduction

```bash
git clone https://github.com/link-foundation/js-ai-driven-development-pipeline-template t && cd t
echo '# touch' >> scripts/simulate-fresh-merge.sh
git -c user.name=r -c user.email=r@x commit -qam 'touch a shell script'
GITHUB_EVENT_NAME=push node scripts/detect-code-changes.mjs | grep changed=
```

Observed (at 0a62b80):

```
js-changed=false
docs-changed=false
any-code-changed=false
```

## Workaround

Touch a file with a counted extension in the same PR (a changelog fragment alone does not help: `.md` is excluded from code changes).

## Suggested fix

In `scripts/detect-code-changes.mjs:362` add `sh`:

```js
const codeFileExtensionPattern = /\.(mjs|cjs|js|json|sh|yml|yaml)$/;
```

Add a regression test that `scripts/simulate-fresh-merge.sh` counts as a code change while `docs/**`, `changelog.d/**` and `dev/log/**` do not.
