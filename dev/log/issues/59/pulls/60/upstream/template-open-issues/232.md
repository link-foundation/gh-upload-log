# 232 Changeset check fails every Dependabot PR: exempt PRs authored by dependabot[bot]

## Summary

The pull-request changeset/fragment check (`.github/workflows/release.yml`, which runs `scripts/validate-changeset.mjs`) requires a release note from **every** PR that touches source or manifests, including PRs opened by Dependabot. Dependabot cannot write a changeset, so in any repository generated from this template that enables Dependabot, every dependency PR fails this check. The check goes red for a reason the PR author (a bot) cannot fix. CI/CD best practice #17 in [hive-mind's CI-CD-BEST-PRACTICES.md](https://github.com/link-assistant/hive-mind/blob/main/docs/CI-CD-BEST-PRACTICES.md) says: "A job that fails for a reason no commit can fix is a false negative, and it trains everyone to ignore red."

## Evidence (downstream)

`link-foundation/lino-objects-codec` uses this template's check. Dependabot's grouped PR [#67](https://github.com/link-foundation/lino-objects-codec/pull/67) failed it in [run 37956144601](https://github.com/link-foundation/lino-objects-codec/actions/runs/37956144601):

```text
##[error]No changeset found in this PR. Add a release note in csharp/.changeset/
##[error]Process completed with exit code 1.
```

The PR was then merged with that check red.

## Reproduce

1. Generate a repository from this template.
2. Add `.github/dependabot.yml` with any ecosystem whose manifest is matched by the check, for example `npm` at `/`.
3. Wait for (or trigger) a Dependabot PR. The changeset/fragment check fails.

## Workaround

Add a changeset to the Dependabot PR by hand, or merge it red.

## Suggested fix

Exempt PRs by **author**, not by branch name. Anyone can push a branch called `dependabot/...`, but only Dependabot opens PRs as `dependabot[bot]`:

```yaml
      - name: Check for changesets
        env:
          PR_AUTHOR: ${{ github.event.pull_request.user.login }}
```

```python
BOT_AUTHORS = ("dependabot[bot]",)

def is_bot_author(author: str | None) -> bool:
    return bool(author) and author in BOT_AUTHORS
# ...in main(), before computing the diff:
if is_bot_author(os.environ.get("PR_AUTHOR")):
    print(f"Skipping: PR opened by {os.environ['PR_AUTHOR']}")
    return 0
```

The same change applied to all four languages, with tests, is in [lino-objects-codec#72](https://github.com/link-foundation/lino-objects-codec/pull/72), commit `b1a818a` (see `python/scripts/validate_changeset.py`, `js/scripts/validate-changeset.mjs`, `csharp/scripts/check-changeset.mjs`, `rust/scripts/check-changelog-fragment.mjs`).
