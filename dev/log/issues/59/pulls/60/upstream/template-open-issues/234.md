# 234 actions/checkout@v6 and actions/setup-node@v6 are a major behind (v7.0.1 and v7.1.0)

## Problem

At the current default branch, the template uses `actions/checkout@v6` (33 uses) and `actions/setup-node@v6` (16 uses). The latest releases are checkout v7.0.1 and setup-node v7.1.0.

checkout v7.0.0 (2026-06-18) also refuses to check out fork PR code under `pull_request_target` and `workflow_run` (actions/checkout#2454).

## Reproduction

```sh
grep -rhoE 'uses: actions/[a-z-]+@[^ ]+' .github | sort | uniq -c
gh api repos/actions/checkout/releases/latest --jq .tag_name     # v7.0.1
gh api repos/actions/setup-node/releases/latest --jq .tag_name   # v7.1.0
```

## Fix

Bump both to v7 everywhere. A Dependabot `github-actions` ecosystem entry, or a test that every `uses: actions/<name>@` shares one major, would keep them current.
